# Sleep Timer Pro

A desktop sleep timer for Windows 11. Set a number of minutes, choose Suspend or Shutdown, and the app will put your computer to sleep (or turn it off) when the time runs out. Designed for falling asleep to podcasts or videos — start the timer, minimize it, and let it do its job. The last-used settings are remembered between sessions.

## Build

The Windows `.exe` is built automatically by GitHub Actions on every push to `main`. Go to the **Actions** tab, open the latest run, and download the `SleepTimerPro-Windows` artifact.
